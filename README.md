# Fundacja Rodzinna × España

Kompleksowy przewodnik po podatkach i obowiązkach polskiej fundacji rodzinnej (Fundacja Rodzinna) inwestującej w nieruchomości w Hiszpanii.

## Zawartość

- **Czym jest Fundacja Rodzinna** — marco legal, ventajas, estructura
- **Mapa podatkowa** — ITP, IBI, IRNR, Patrimonio, plusvalía, retención 3%
- **Proces zakupu** — krok po kroku od Polski do wpisu w Registro de la Propiedad
- **Konwencja o unikaniu podwójnego opodatkowania** (Polska — Hiszpania, 1979)
- **Agencia Tributaria** — jak widzi fundację, kontrole, obowiązki deklaracyjne
- **Ryzyka podatkowe** — najem krótkoterminowy, flipy, rezydencja fundatora, norma antyabuzywna
- **Kalkulator podatkowy** — szacunkowe obliczenia kosztów zakupu i utrzymania
- **Usługi i pakiety** — doradztwo, reprezentacja, rozliczenia, obrona

## Technologia

- HTML5 / CSS3 / JavaScript (vanilla)
- Responsive design (mobile-first)
- Google Fonts: Playfair Display + Inter
- Zero dependencies — statyczna strona

## Uruchomienie

Otwórz `index.html` w przeglądarce lub uruchom dowolny serwer statyczny:

```bash
# Python
python3 -m http.server 8080

# Node.js
npx serve .
```
