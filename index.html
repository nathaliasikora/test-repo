Czy odkrywasz teraz obowiązki podatkowe?

Modelo 210, Podatek od Wielkich Fortun i inne obowiązki, o których Twój agent nieruchomości nie poinformował Cię przy zakupie.

Czy agent może powiedzieć „ja nie jestem doradcą podatkowym"?

Orzecznictwo Sądu Najwyższego jest jasne: nie zawsze. Gdy agencja nieruchomości działa jako profesjonalista oferujący doradztwo (nie tylko pośrednictwo), ma prawny obowiązek informowania o wszystkich istotnych obciążeniach ekonomicznych wpływających na rzeczywisty koszt transakcji.

Jeżeli agent nie dopełnił tego obowiązku, możesz dochodzić odszkodowania. Skontaktuj się ze mną, aby dowiedzieć się więcej o swoich prawach.
